# Snapmaker U1

The U1 runs Klipper and Moonraker, so it gets [everything a Klipper printer gets](klipper.md), plus:

- **Four toolheads.** Each toolhead with its own nozzle temperature, and which one is active.
- **Filament on each nozzle.** The colour, material and maker the U1 reports for every nozzle.
- **Top cover purifier.** If the top cover is fitted, its mode and fan speeds (exhaust and inner fan), and you can set them from the page.
- **Chamber temperature** from the U1's cavity sensor.
